
# ATS_Resume_Screening_Analytics

## Overview
ATS_Resume_Screening_Analytics is a web-based application designed to analyze resumes and provide insights for better recruitment decisions. The system helps HR professionals and recruiters by automatically screening resumes, scoring them based on predefined criteria, and presenting analytics to identify the best candidates efficiently.

## Features
- Resume parsing and data extraction
- ATS compatibility scoring
- Dashboard for analytics and insights
- Export reports in CSV/Excel format
- User-friendly interface

## Technology Stack
- Backend: Python (Flask/Django)
- Frontend: HTML, CSS, Bootstrap
- Database: SQLite/MySQL
- Additional Libraries: pandas, openpyxl (for Excel export), PyPDF2 (for PDF parsing)
